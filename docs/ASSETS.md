# Generated illustration provenance

These five illustrations were created with the built-in ImageGen tool for the user's supplied visual reference. They are artwork for this portfolio, not photographs or screenshots of deployed projects. No people, portraits, human avatars, or resume files were generated. Lossy WebP conversion at quality 86 was used only to optimize the generated raster assets; the laptop retains its native transparency.

The original outputs remain in the Codex generated-images folder. Project-bound WebP files live in `public/assets/` and are used by `src/components/Visuals.jsx`.
